# NyayaLLM: Indian Criminal Law Assistant

This is a companion Space for the **NyayaLLM** model, fine-tuned on an AMD MI300X to provide expert assistance for the 2023 Indian Criminal Laws (BNS, BNSS, BSA).

## How to use
Simply type your question about the new criminal laws, and NyayaLLM will provide the corresponding sections and legal procedures.
